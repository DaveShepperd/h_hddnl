# h_hddnl

This is the "host" version of hddnl. As opposed to the version of hddnl running on the game hardware.

This host application communicates with the game hardware version of hddnl using a TCP/IP connection.

This tool will only work with game hardware that includes:

1) Either the standalone hddnl "game code" booted or
2) hddnl built directly into the game and
3) The game hardware has Ethernet and
4) the game has a TCP/IP stack running on it and
5) the game can be be reached via a TCP conection by this application.

Otherwise, this application is of no use to anyone.
